# Portfolio - Ange KOUMBA

Portfolio professionnel d'Ange KOUMBA, Data Scientist et Développeur Full-Stack.

## 🚀 Technologies utilisées

- HTML5 / Tailwind CSS
- JavaScript (ES6+)
- EmailJS pour le formulaire de contact
- AOS pour les animations
- Typed.js pour l'effet de texte dynamique

## 🌐 Fonctionnalités

- Design responsive
- Changement de langue (FR/EN)
- Téléchargement CV bilingue
- Formulaire de contact fonctionnel
- Animations fluides

## 📦 Installation locale

```bash
# Cloner le repository
git clone https://github.com/kay1403/Ange_Koumba_PortFolio.git

# Installer les dépendances
npm install

# Lancer en développement
npm run dev

# Builder pour la production
npm run build:all
